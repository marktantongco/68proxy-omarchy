# 68proxy Omarchy — OpenAI / Anthropic Gateway for Command Code on Arch Linux

> Plug-and-play local proxy for Omarchy Linux. Translates OpenAI and Anthropic APIs to Command Code.

Original: evanfu0110/68proxy | This Fork: Omarchy Linux native

## One-Liner Install

```bash
curl -fsSL https://raw.githubusercontent.com/marktantongco/68proxy-omarchy/main/install.sh | bash
```

## What is 68proxy?
- Exposes /v1/chat/completions (OpenAI), /v1/messages (Anthropic), /v1/models, /health
- Converts to Command Code CLI envelope
- UI: Console, Relay Records, Models, Tool Integration, Debug Logs

## Why Omarchy Build?
- deb/AppImage/binary + AUR packages
- English default
- Walker (Super+Space) + Hyprland integration
- XDG config ~/.config/68proxy/config.json

Built with Tauri 2 + Rust + React 19 + WebKitGTK
